## 📌 Sobre o Projeto

O **BBC** é um website institucional desenvolvido para apresentar a empresa, suas áreas de atuação e seus diferenciais de forma clara e sofisticada.

O projeto combina **design responsivo, navegação fluida e elementos visuais cinematográficos**, com foco em uma experiência intuitiva e em facilitar o contato direto com a equipe.

---

## ✨ Destaques e Funcionalidades

- 🎬 **Hero cinematográfico:** vídeos de fundo, imagem alternativa e apresentação de impacto.
- 🪟 **Liquid Glass:** superfícies translúcidas, reflexos sutis e estética corporativa contemporânea.
- 📱 **Design responsivo:** experiência adaptada para desktop, tablet e dispositivos móveis.
- 🧭 **Navegação suave:** menu responsivo e rolagem animada entre seções.
- ✨ **Animações elegantes:** transições e revelações ao rolar a página, com respeito à preferência por movimento reduzido.
- 💬 **Contato via WhatsApp:** formulário com máscara de telefone, validação e mensagem pré-preenchida.
- ❓ **FAQ interativo:** perguntas frequentes com abertura e fechamento animados.
- 🔎 **SEO & Open Graph:** metadados, favicon personalizado e imagem para compartilhamento.

## 🚀 Como Executar

**Pré-requisitos:** Node.js compatível com o projeto e npm.

**1. Clone o repositório** (substitua a URL pelo endereço real quando ele estiver publicado):

```bash
git clone <URL_DO_REPOSITORIO>
cd <PASTA_DO_PROJETO>
```

**2. Instale as dependências:**

```bash
npm install
```

**3. Inicie o ambiente de desenvolvimento:**

```bash
npm run dev
```

Acesse **http://localhost:3000** no navegador.

**4. Verifique o build de produção:**

```bash
npm run build
```
